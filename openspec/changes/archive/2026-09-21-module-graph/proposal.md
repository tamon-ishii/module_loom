## Why

Python プロジェクトの大規模化に伴い、モジュール間の複雑な依存関係や循環インポート、特定モジュールの巨大化（肥大化）がメンテナンス性を著しく低下させる問題が発生します。
Graph-It-Live のようなリアルタイムかつ直感的な依存関係グラフをローカル環境で軽快に利用できるようにし、Rust による高速な静的解析と Tauri によるデスクトップ GUI、さらに PyCharm や VS Code などの主要エディタとの連携を提供することで、コードベースの健全性を迅速に把握・改善できるようにします。

## What Changes

- **Rust 製高速解析エンジン**:
  - Python ソースコードのインポート関係（絶対・相対インポート）の高速パース
  - 循環インポート（Circular Imports）の検出およびサイクル経路の特定
  - モジュールの巨大化監視（行数、定義シンボル数、依存数等のメトリクス計算）
  - 型アノテーションおよび型チェック情報（ty / 型チェッカー）の解析・警告連携
- **Tauri ベースのモジュールグラフ GUI**:
  - Graph-It-Live を参考にしたインタラクティブなノード・エッジによるグラフ描画
  - 循環参照のハイライト、巨大化モジュールの警告表示（色やサイズの変化）、フィルタリング機能
  - 解析メトリクスの詳細パネル表示
- **外部エディタ（PyCharm / VS Code）連携**:
  - グラフノードや警告箇所をクリックした際、PyCharm や VS Code の対象ファイル・行へ即座にコードジャンプ

## Capabilities

### New Capabilities
- `module-analysis`: Python コードの高速解析（依存関係・循環インポート・メトリクス/巨大化・型チェック情報）を行う Rust 解析コア
- `graph-visualization`: Tauri およびフロントエンドを用いた Graph-It-Live ライクなインタラクティブグラフ可視化
- `editor-integration`: PyCharm（JetBrains URL スキーム / CLI）や VS Code へのファイル・行ジャンプ連携
